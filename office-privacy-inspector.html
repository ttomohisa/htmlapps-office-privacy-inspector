使い方と注意事項

基本操作

  1. DOCX / XLSX / PPTXを選択するか、画面へドロップします。
  2. 作成者情報、文書情報、カスタムプロパティを確認します。
  3. 削除対象を選んでクリーンアップ済みコピーを作成します。生成後は自動で再検査し、削除前 / 削除後と残っている確認項目を表示します。元ファイルは上書きしません。

プライバシー

Officeファイルの読み込みと解析はブラウザ内で行われ、このアプリから外部サーバーへ送信されません。実行時の外部通信もCSPで無効化しています。

現在確認できるもの

  • Core Properties（作成者、最終更新者、作成日時、最終印刷日時など）
  • Extended Properties（会社名、管理者名、編集時間、Officeアプリ情報など）
  • Custom Properties（独自プロパティ名・型・値）
  • DOCX: コメント、変更履歴、非表示テキスト、編集セッション情報、外部参照、埋め込み要素、Custom XML
  • XLSX: 非表示 / Very Hiddenシート、非表示行列、外部参照、定義名、接続、Pivot / Slicer Cache、埋め込み要素、Macro関連part
  • PPTX: コメント、発表者ノート、非表示スライド、スライド外オブジェクト、外部参照、埋め込み要素、Custom XML、Macro関連part

注意事項

  • 本文や画像内の機密情報まで自動判定する機能や、検出項目の削除は後続バージョンで追加します。
  • 今回の検査で何も見つからなくても、ファイル内に機密情報が存在しないことを保証するものではありません。
  • 暗号化・パスワード保護されたOfficeファイルや旧形式の DOC / XLS / PPT には対応していません。
